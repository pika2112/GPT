Sistema de Chamadas 3.0.0 — generic edition

This release retains the existing call, workstation and per-IP role behavior and
adds shared configurable pharmacy naming. Existing files without configuration
default to Farmácia; invalid configuration is rejected without overwriting data.

Windows CI gates publication on 20 automated Node tests, the real packaged
desktop smoke test, and final ZIP structure verification. New checks cover name
persistence, multi-client synchronization, restart, invalid names, disk failures,
native notification titles, safe text rendering, mobile layout and JSON backup.
Runtime/tray icons are generated from new neutral artwork at build time.
Manual screenshots are captured from the new generic UI in the smoke test.

The local execution environment was unavailable; Windows build, tests, PDF
generation and packaging are performed on GitHub Actions. The actual pharmacy
PCs, firewall, native focus/sound and reboot/login behavior still need the
on-site checklist. Windows 10/11 x64; Electron 44.7.2. Build is unsigned.
