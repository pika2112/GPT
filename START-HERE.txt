SYSTEM OF CALLS — VERSION 2.0

1. Save Sistema-Chamadas-2.0.0-Windows.exe in a permanent folder on the
   Back Office Windows PC and double-click it. No Node.js installation is needed.
   This is an unsigned app; Windows may show a security warning.
2. Keep this PC awake. Allow TCP port 3000 on the store's private network.
3. Right-click the blue app icon near the Windows clock. Under
   "Endereços para colaboradores", click an address to copy it.
4. On other PCs in the same network, open that address in a browser and select
   "Colaborador". The desktop app opens as Back Office.
5. Closing the desktop window hides it in the system tray. A new call restores
   the window and sends a Windows notification. Double-click the tray icon to open it.
6. Optional: enable "Iniciar com o Windows" from the tray menu.
   Do not move the EXE after enabling startup.
7. To stop the server, use "Sair e parar o serviço…" from the tray menu.

THE LOG IS INSIDE THE APP
Filter the Back Office history by date, state, or call ID. See waiting-time
statistics and a seven-day chart. Browse every record using the page buttons.
"Exportar CSV filtrado" exports the currently filtered records for Excel.
"Cópia JSON completa" exports a full backup. Calls survive app/server restarts.
Dates in the app use the viewer's local time zone; CSV timestamps use UTC.

LIMITS
The Back Office PC must stay powered on, awake and connected to the network.
Windows may limit foreground focus or suppress notifications in Do Not Disturb.
Use only on a trusted local network; this version has no user authentication.
Native Windows notification, firewall and startup behavior needs a check on your PC.
The code and browser flows passed automated tests in the build environment.
