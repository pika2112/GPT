FARMÁCIA FARIA 2.0.4 — WINDOWS 8

Se já tem uma versão instalada, leia primeiro ATUALIZAR.txt.

1. Extraia TODOS os ficheiros do ZIP para uma pasta fixa, por exemplo
   C:\FarmaciaFaria\Chamadas\ (ou uma pasta onde tenha permissões de escrita).
2. Execute Iniciar.cmd. Mantenha EXE, DLLs, resources e locales juntos.
3. O Back Office abre com o resumo de HOJE e as últimas chamadas do dia.
   O painel atualiza automaticamente quando chega uma chamada e à meia-noite,
   usando o horário de Lisboa. Chamadas pendentes de ontem continuam visíveis.
4. "Histórico e análise" abre as métricas adicionais, os filtros e os registos
   de outros dias. Pode exportar o dia em XLS, os registos filtrados em XLS,
   e, em Definições → Cópia de segurança, guardar uma cópia JSON completa.
5. Em "Definições" → "Postos da farmácia", associe IPs a nomes (ex.: 10.21.225.20 → Marcelo).
   Faça uma chamada de cada posto para descobrir o IP real nessa lista.
   Reserve os IPs no router. O IP identifica o computador, não uma conta pessoal.
6. Em "Definições" → "Arranque da aplicação", ative o início automático depois de iniciar
   sessão no Windows. Guarde primeiro a pasta na localização definitiva.
7. Outros computadores da mesma rede usam o endereço no navegador, por exemplo
   http://10.21.225.7:3000, e escolhem Colaborador.
8. O X esconde a janela na área de notificação. Uma chamada volta a abri-la.
   Para parar totalmente, use "Sair e parar o serviço…" no menu desse ícone.

DADOS
O histórico e os nomes por IP ficam em:
  %APPDATA%\sistema-chamadas-loja\dados\chamadas.json
A atualização conserva estes registos. Chamadas antigas que não guardavam
IP aparecem como "Posto não registado"; não é possível recuperar o IP passado.

DIAGNÓSTICO
Se não abrir, Iniciar.cmd mostra o código de saída.
Veja diagnostico-console.log e diagnostico-electron.log nesta pasta, ou
%APPDATA%\sistema-chamadas-loja\arranque.log.
O PC principal deve ficar ligado, sem suspensão e na rede da farmácia.
Permita apenas a rede privada na Firewall do Windows (porta TCP 3000).

COMPATIBILIDADE
Usa Electron 22 para compatibilidade com Windows 7/8/8.1.
Esse runtime antigo não recebe atualizações de segurança.
Use apenas numa rede local de confiança. Não existem contas/autenticação.
O programa não tem assinatura digital; não precisa de instalar Node.js.

AJUSTES 2.0.4
O alerta pulsa a vermelho, sem logótipo (a opção de reduzir movimento mantém
um alerta vermelho estático). A marca usa o vetor original fornecido.
As exportações são XLS verdadeiros; a cópia JSON está apenas nas Definições.
Históricos com mais de 65.535 registos são divididos em folhas no mesmo XLS.
