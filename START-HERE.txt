SISTEMA DE CHAMADAS 2.0.1 — WINDOWS 8 COMPATIBILITY

1. Download Sistema-Chamadas-2.0.1-Windows8.zip and EXTRACT ALL files.
2. Open the extracted folder and double-click Iniciar.cmd.
   Keep the EXE, DLLs, locales and resources together. Do not move only the EXE.
3. The Back Office window opens. Allow the private-network firewall prompt.
4. Right-click the blue tray icon near the clock. Under
   "Endereços para colaboradores", click an address to copy it.
5. Other computers on the same local network use that address in their browser.
   Choose Colaborador to send calls. The main PC must remain awake.
6. Closing the desktop window hides it in the tray; a call brings it back.
   Double-click the tray icon to reopen. Use the tray menu to quit completely.

If it still does not open, Iniciar.cmd keeps a console open with the exit code.
It writes diagnostico-console.log and diagnostico-electron.log in this folder.
The app writes %APPDATA%\sistema-chamadas-loja\arranque.log.
Send the exit code and the last lines of these logs to diagnose startup.

History and CSV/JSON export are inside Back Office.
Saved history remains in %APPDATA%\sistema-chamadas-loja\dados.
The original 2.0.0 package requires Windows 10+ and does NOT support Windows 8.
This version uses Electron 22, the last series supporting Windows 7/8/8.1.
Windows 8 and this legacy runtime no longer receive security updates;
use only on a trusted local network. The application has no user authentication.
It is unsigned. No Node.js installation is needed to run the extracted app.
