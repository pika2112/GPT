Se já usa o programa, leia ATUALIZAR.txt antes de copiar qualquer pasta.

PRIMEIRA INSTALAÇÃO
1. Extraia o ZIP inteiro para uma pasta temporária.
2. Copie a pasta FarmaciaFaria para C:\
   Resultado: C:\FarmaciaFaria\Chamadas\ e C:\FarmaciaFaria\Manuais\.
   Se não tiver permissões, copie-a para %LOCALAPPDATA%\.
3. Abra Chamadas e execute Iniciar.cmd.
   Mantenha todos os ficheiros dessa pasta juntos; não copie apenas o EXE.
4. Permita a porta TCP 3000 apenas na rede privada da farmácia.
5. Os restantes computadores abrem http://10.21.225.7:3000 no navegador.
   Use o IP atual do computador principal se for diferente.
6. Escolha a função de cada IP uma vez: Back Office ou Colaborador.
   A última escolha fica guardada no servidor.
7. Em Definições, associe os nomes aos IPs e ative o arranque com o Windows.
   A pasta tem de estar na localização definitiva antes de o ativar.
8. Siga Manuais\TESTE-FINAL.txt antes de usar durante o atendimento.

O X esconde a janela. Para encerrar use o ícone junto ao relógio:
"Sair e parar o serviço…".

DADOS — CONSERVAR
%APPDATA%\sistema-chamadas-loja\dados\chamadas.json
O histórico, os nomes e as funções por IP ficam fora da pasta do programa.
Não apague %APPDATA%\sistema-chamadas-loja.
As cópias JSON são feitas em Definições → Cópia de segurança.
O PC principal deve ficar ligado, sem suspensão e com a aplicação a correr.
